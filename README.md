# Hi, I'm Renzo Alessandro 👋
### Software Engineer | Frontend · Full Stack · Unreal Engine & Blender

Computer Science graduate and software developer based in **Arequipa, Perú**. I build web applications and business systems with **React**, **Angular**, **Node.js**, and **TypeScript**, working across frontend and full stack — from UI and APIs to databases, testing, and deployment. In parallel, I work as a **game developer and 3D technical artist**, creating stylized characters and optimized real-time assets with **Blender**, **Unity**, and **Unreal Engine 5**.
